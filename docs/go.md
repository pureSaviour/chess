# 围棋玩法与开发边界

更新：2026-09-15。

## 规则基线

本实现参考用户指定的 [WeiqiGo 入门规则](https://weiqigo.com/zh-cn/how-to-play/)、[中华围棋协会规则](https://cwqa.qilue.com/rules/) 与[中国围棋协会公开规则](https://wqwh.weiqi.org.cn/rules/)，采用中国规则的程序内可判定部分：标准 19 路、黑先、气尽提子、禁着点、禁止全局同形、双方连续虚着进入终局、数子法和黑贴 3 又 3/4 子（以点数显示为白方加 7.5 目）。

`GoGame` 是唯一权威规则聚合。`Place` 先模拟落子及相邻敌方无气棋块的提取，再检查己方有气和位置全同；任何拒绝都会完整恢复局面。全同判断使用落子后的黑白占位，不把轮次或虚着写进棋形。`Pass` 不受全同限制；连续两次虚着从 `Playing` 进入 `Scoring`。

程序不猜测活棋与死棋。数子阶段由轮到的一方点击棋块，整块切换死子标记；每次修改会清空双方此前确认。黑白依次确认同一标记后，领域层移除死子语义并计算活子与所围空点；双方接触或无归属的空区各得一半。认输在行棋或数子阶段都可结束对局。裁判介入、让子棋、超时、三劫循环按赛事补充规定判无胜负等人工赛务规则当前未实现。

“数目估算”可在任意局面显式进入，但属于本地非正式分析：它从当前快照复制占位，用户点击棋子后只在副本中切换整条同色棋链的死子假设，再复用正式面积算法计算黑白区域、贴目与暂时领先。估算期间权威操作按钮禁用，退出后不保留标记；若联网对手产生新着，界面按 `ActionNumber` 立即关闭旧估算。估算不写棋局、操作日志、计时、网络或 SGF，也不会自动判断劫、双活及未定型棋块。联机双方看到的是各自私有分析结果，不构成数子提案或双方确认。

## 分层、网络与所有权

`GoSnapshot` 是只读展示快照，并为仍在盘面的棋子携带其落子手数；提子及非法落子回滚会同步移除或恢复该投影信息。`GoBoardView` 只负责 19×19 网格、星位、棋子、死子/估算标记、区域覆盖、命中、边缘坐标和可选手数文字。棋盘使用左侧全部可用布局空间并按短边绘制正方形；联网聊天保留独立右栏。坐标采用 A–T 跳过 I，行号从白方下边缘 1 到上边缘 19；局内设置可即时开关坐标或棋子手数，开关不进入棋谱、协议或规则状态，当前不跨对局持久化。手数文字按棋子直径测量并缩小，黑白棋分别使用对比色；最新落子始终绘制对比色圆环，开启手数时仍保留，因此本地与联机双方读取同一快照即可获得一致提示。

`IGoMatchController` 是 UI 的意图入口。本地实现拥有一个纯托管 `GoGame`；LAN/Steam 实现复用 `ITwoPlayerPacketTransport`、双人聊天和玩家资料，但使用独立围棋 v1 协议。房主发布执色和完整有界语义操作日志，客户端从空局逐条重放；客户请求携带预期操作序号。版本、大小、枚举、坐标、角色、序号或领域重放失败时保持旧局面并提示。事件在 transport 驱动线程同步发布，Godot 适配器在主线程泵入；控制器退出时解绑并幂等释放 transport。当前采用可信 P2P 房主模型，不提供中立裁判、断线续局或房主迁移。

## 棋谱、记录与回放

`GoGameRecord` 保存标准主线、双方确认的死子集合和终局结果。`GoSgfCodec` 写 UTF-8 SGF FF[4]/GM[1]，固定 `SZ[19]RU[Chinese]KM[7.5]`；落子使用 `B/W`，虚着使用空值，胜负使用标准 `RE`，确认移除的死子放在终局 `AE` 节点。读取限制 1,000,000 字符，拒绝错误棋种、路数、规则、贴目、坐标、轮次和不一致结果，返回前必须通过完整领域重放。

`GoRecordStore` 拥有 `user://games/go.chinese/records/recent|saved`。终局自动写 recent 并保留十局；对局内可直接保存，最近记录页也可追加到 saved，原 recent 不删除。最近/保存记录均可复验后导出 `.sgf`；展示用 `.meta.json` 不进入标准棋谱。页面持有头像纹理并在退出时释放。

## 当前入口、测试与限制

画廊模块 `go.chinese` 提供本地双人、LAN、Steam、最近对局和保存对局五个入口；没有 AI、人机设置或复盘分析入口。已实现的任意时刻数目功能仅为手动死子假设后的本地面积估算，不是 AI 终局预测，也不替代双方正式确认。核心自运行测试覆盖提子、自杀、全同、双虚、死子确认、正式/估算数子、估算隔离、认输、手数投影、SGF 往返/拒绝和房主权威同步。Godot UI smoke 覆盖模块实例化、棋盘自适应尺寸、联机聊天可见边界、局内坐标/手数开关、手动估算覆盖层和最新一手提示。真实双机 LAN、Steam 双账号、触屏标记、不同分辨率以及复杂双活/劫争估算的人工视觉与规则体验仍未验收。
